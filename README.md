# Homebrew Tap

Homebrew formulae for [CHOAM](https://github.com/jlmalone/choam) and related tools.

## Install

```bash
brew tap jlmalone/tap
brew install choam
```

## Update

```bash
brew update
brew upgrade choam
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `choam` | Cross-machine file synchronization for large media repositories |
